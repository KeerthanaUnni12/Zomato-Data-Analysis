## Objective
The goal of this project is to explore and analyze a Zomato dataset to understand customer preferences, restaurant types, and key factors that influence ratings and services in the food delivery and dining industry.

---

##  Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

##  Dataset
The dataset is a CSV file containing details of various restaurants listed on Zomato. Key features include:
- Restaurant Name
- Location
- Rating
- Type (Delivery/Dine-out)
- Online Order availability
- Cuisine
- Approximate cost for two, etc.

---

##  Data Preprocessing
- Loaded the CSV using Pandas
- Cleaned the `rate` column to extract numerical values from strings like "4.1/5"
- Checked and explored data types, null values, and overall structure using `.info()`

---

##  Exploratory Data Analysis (EDA)
The EDA section includes:
- Countplot of restaurant types to understand distribution
- More visualizations and insights to be added (e.g., cuisine popularity, rating trends, cost distribution)

---

##  Insights 
- Delivery-based restaurants are most common
- Online ordering is popular among high-rated restaurants
- Some restaurant types or cuisines are location-specific
